思考与探索

01｜从一条弧线开始 我最初想做一个弧线导航栏，但还不知道怎样用代码实现。于是，我跟着 AI 一边尝试，一边理解元素的排列与定位，也开始体会到：把脑海中的形状搬到网页上，需要不断调整。 --→
02｜多一层导航 我希望纵向切换不同栏目，横向选择栏目里的内容。为了实现这个二维导航，我接触了 HTML、CSS 和 JavaScript 之间的配合：按钮怎样找到对应内容，页面怎样切换显示，以及怎样标记当前选中的项目。 --→
03｜用线条引导视线 做完导航后，我开始想：怎样让人更容易看懂页面的布局？我想起之前做导航的时候学到的 linear-gradient，尝试用渐变画出线条：用纵向虚线引导导航区域，再用横线提示内容展示的范围，让导航与内容在视觉上建立联系。 --→
