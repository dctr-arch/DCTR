# 种种树 · 海岛造林原型

直接用浏览器打开 `dist/index.html` 就能玩，无需安装依赖、无需联网。

也可以运行 `node serve.cjs`，访问终端打印的本地地址。

地图限定为一座架空的小岛。以共同造林、坚持积累、生态逐渐涌现为精神内核，地形不复刻真实三北地区。

操作：WASD / 方向键移动像素角色，或点击岛上土地让角色走过去；E / 空格在角色身边种树，按住可边走边种。鼠标点击土地不会直接种树。1/2/3 切换树种。右键拖动平移，滚轮缩放，手机可用方向按钮和种树按钮。海岸是移动及种植边界。时间按钮可切换 4 倍生态时间，角色保持正常移动速度。刷新或重新开始会清空本轮。

保留草案核心：梭梭、沙柳、花棒的存活和生态贡献差异，树苗扎根判定与持续自然损耗，树木聚集庇护，风沙随树木减少，草地/动物/水源自动涌现，阶段手记，绿洲镜头拉远，结局后继续游玩。

为了快速看见核心玩法，阶段阈值改为 12、36、80 棵存活树；约 3 秒判定扎根。没有金币、资源消耗或手动放置草、水、动物。动物只是视觉表现，不做复杂生态模拟。叙事是原型创作，并非引用真实人物记录。
